# 🌃 EcoLight Maestro: Time & Intensity Adaptive Street Light Automation

An embedded systems project built using the **LPC2148 ARM7 Microcontroller** to automate street lighting based on **RTC scheduling** and **ambient light intensity**. The system uses an **LDR** to detect surrounding light and automatically controls street lights, improving energy efficiency.

### 🔹 Features
- RTC-based street light scheduling (6 PM – 6 AM)
- Automatic light control using LDR and ADC
- LCD display for real-time date and time
- Keypad-based RTC configuration
- External interrupt for RTC editing
- Embedded C implementation

### 🛠️ Tech Stack
- Embedded C
- LPC2148 (ARM7)
- Keil μVision
- Flash Magic

### 🔩 Hardware
- LPC2148 Development Board
- LCD
- LDR Sensor
- Matrix Keypad
- LEDs
- Push Button
- Buzzer
