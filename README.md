# 🌃 EcoLight Maestro: Time & Intensity Adaptive Street Light Automation

An embedded systems project developed using the **LPC2148 ARM7 Microcontroller** to automate street lighting based on **RTC scheduling** and **ambient light intensity**. The system uses an **LDR** to detect surrounding light and automatically controls street lights, improving energy efficiency. The project was designed and tested using **Proteus simulation**.

## ✨ Features
- RTC-based street light scheduling (6:00 PM – 6:00 AM)
- Automatic light control using LDR and ADC
- LCD display for real-time date and time
- Keypad-based RTC configuration (`#` key)
- Input validation for RTC settings
- Developed in Embedded C

## 🛠️ Tech Stack
- Embedded C
- LPC2148 (ARM7)
- Keil μVision
- Proteus
- Flash Magic

## 🔩 Simulation Components
- LPC2148
- LCD Display
